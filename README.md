# arp-scanner

Bash-скрипт для ARP-сканирования адресов IPv4 в сетях с маской `/24`.
Адрес рассматривается как `PREFIX.SUBNET.HOST`, где `PREFIX` — первые два октета.

## Возможности

- Три режима сканирования в зависимости от переданных аргументов:
  - весь префикс (`PREFIX.1-255.1-255`);
  - одна подсеть (`PREFIX.SUBNET.1-255`);
  - один адрес (`PREFIX.SUBNET.HOST`).
- Проверка всех аргументов регулярными выражениями (`=~`): каждый октет — число 0–255 без ведущих нулей.
- Проверка существования сетевого интерфейса.
- Проверка запуска с правами root.
- Логика вынесена в функции, повторяющихся блоков кода нет.

## Требования

- Linux, `bash` 4+
- `arping` (версия Thomas Habets, ключ `-i`)
- `iproute2` (команда `ip`)
- Права root

> В пакете `iputils-arping` (стандартный для Debian/Ubuntu) интерфейс задаётся ключом `-I`, а не `-i`.
> Если используется эта версия, замените ключ в функции `scan_ip`.

## Использование

```bash
chmod +x arp_scan.sh
sudo ./arp_scan.sh PREFIX INTERFACE [SUBNET] [HOST]
```

| Аргумент    | Обязательный | Описание                         | Пример    |
|-------------|--------------|----------------------------------|-----------|
| `PREFIX`    | да           | первые два октета                | `192.168` |
| `INTERFACE` | да           | сетевой интерфейс                | `eth0`    |
| `SUBNET`    | нет          | третий октет (0–255)             | `1`       |
| `HOST`      | нет          | четвёртый октет (0–255), только вместе с `SUBNET` | `10` |

### Примеры

```bash
# Весь префикс 192.168.0.0/16 (65 025 адресов)
sudo ./arp_scan.sh 192.168 eth0

# Одна подсеть 192.168.1.0/24
sudo ./arp_scan.sh 192.168 eth0 1

# Один адрес 192.168.1.10
sudo ./arp_scan.sh 192.168 eth0 1 10
```

### Обработка ошибок

```text
$ ./arp_scan.sh 192.168 eth0
Error: this script must be run with root privileges (try: sudo ./arp_scan.sh ...)

$ sudo ./arp_scan.sh 192.300 eth0
Error: $PREFIX has invalid value: '192.300'

$ sudo ./arp_scan.sh 192.168 eth0 256
Error: $SUBNET has invalid value: '256'
```

## Структура скрипта

| Функция       | Назначение                                              |
|---------------|---------------------------------------------------------|
| `usage`       | вывод справки                                           |
| `die`         | вывод ошибки и завершение работы                        |
| `check_root`  | проверка запуска от root                                |
| `require`     | проверка, что обязательный аргумент передан             |
| `validate`    | проверка аргумента регулярным выражением                |
| `scan_ip`     | сканирование одного адреса                              |
| `scan_subnet` | сканирование всех хостов подсети (вызывает `scan_ip`)   |
| `scan_all`    | сканирование всех подсетей (вызывает `scan_subnet`)     |

## Важно

Сканируйте только сети, на сканирование которых у вас есть разрешение.
